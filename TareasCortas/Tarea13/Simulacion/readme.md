Simulación de la comunicación entre cliente, intermediario y servidor de productos, incluyendo el protocolo mancomunado entre islas
## Requisitos

- `g++` con soporte para C++17
- `make`

## Uso

| Comando      | Qué hace                                         |
|--------------|--------------------------------------------------|
| `make`       | Solo compila                                     |
| `make run`   | Compila y ejecuta el menú interactivo            |
| `make auto`  | Compila y ejecuta los 17 casos automáticos       |
| `make clean` | Borra los archivos compilados                    |

## Notas

- Las carpetas `bodegas/` y `bitacora/` se crean solas con `make run` y `make auto`.
